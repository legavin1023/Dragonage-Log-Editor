# Dragonage Log Editor

Vue 3 기반 TRPG HTML 채팅 로그 편집기입니다.

## 실행

```sh
npm install
npm run serve
```

PowerShell의 스크립트 실행 정책으로 npm 실행이 차단되면 `npm.cmd run serve`를 사용하세요.

## 사용

1. HTML 파일을 불러오거나 **협죽도의 아가리 로그 열기**를 선택합니다.
2. 미리보기에서 `chatlog__message-group` 대화를 클릭합니다.
3. GM 이름과 내용을 입력하고 **선택한 대화 뒤에 추가**를 누릅니다. Ctrl/Command + Enter도 사용할 수 있습니다.
4. 추가한 GM 메시지를 선택하면 내용 불러오기, 수정 적용, 삭제가 가능합니다. **되돌리기**는 마지막 편집을 복원합니다.
5. **HTML 저장**을 눌러 `_편집본.html` 파일을 다운로드합니다. 원본 파일은 변경하지 않습니다.

동일한 이름의 기존 인물이 있으면 초상화와 메시지 색상을 재사용합니다. 내용은 일반 텍스트로 삽입하며 줄바꿈을 유지합니다. 추가한 GM 메시지는 저장 후 다시 불러와도 수정할 수 있습니다. 입력만 하고 추가하지 않은 내용은 HTML에 포함되지 않습니다.

로그는 브라우저 안에서 처리하며 서버로 업로드하지 않습니다. 외부 이미지나 글꼴을 참조하는 다른 HTML은 표시 과정에서 해당 주소에 접근할 수 있습니다. 가져온 HTML의 실행 스크립트와 이벤트 속성은 제거됩니다. 미리보기의 선택 표시와 키보드 탐색용 속성은 편집본에 포함하지 않습니다.

## 빌드

```sh
npm run build
```

## 티스토리용 내보내기

편집 후 **티스토리용 내보내기**를 누르면 HTML 복사, 게시용 파일 저장, 본문 미리보기가 표시됩니다.

1. 티스토리 글쓰기에서 HTML 모드로 전환합니다.
2. **HTML 복사**로 복사한 코드를 붙여 넣습니다. 복사가 차단되면 선택된 코드에서 Ctrl/Command + C를 누릅니다.
3. 편집 모드를 바꾸지 말고 미리보기를 확인한 뒤 글을 저장합니다. 저장된 글을 PC와 모바일에서 확인하세요.

문서 전체의 html/head/body/meta 태그를 제외하고, CSS는 출력마다 고유한 로그 영역으로 제한합니다. 반응형 규칙과 초상화 CSS를 유지하며 내장 웹폰트는 시스템 글꼴로 대체합니다. 편집기 선택 표시와 키보드 탐색 속성도 제거합니다. 재편집용 원본 백업은 **HTML 저장**을 사용하세요.

초상화·이미지는 원본의 Base64 데이터나 주소를 유지합니다. 티스토리 에디터의 정리 처리, 실제 스킨 CSS, 이미지 저장 정책까지 보장하는 기능은 아닙니다. 저장 후 이미지가 사라지면 티스토리에 이미지를 업로드해 주소를 교체해야 합니다. 외부 스타일을 읽지 못하면 제외한 개수를 표시합니다. 입력 중인 GM 내용은 실제로 추가한 후 내보내야 합니다.

## 내보내기 검사

```sh
npm test
```

실제 샘플의 메시지 보존, CSS 범위 제한, 원본 불변성, 폰트 제거, GM 줄바꿈·특수문자, 외부 스타일 경고를 검사합니다. 티스토리에서 실제 글을 저장하는 통합 검사를 대체하지 않습니다.
