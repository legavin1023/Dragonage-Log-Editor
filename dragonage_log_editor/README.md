# Dragonage Log Editor

Vue 3 기반 TRPG HTML 채팅 로그 편집기입니다.

## 실행

```sh
npm install
npm run serve
```

PowerShell의 스크립트 실행 정책으로 npm 실행이 차단되면 `npm.cmd run serve`를 사용하세요.

## 사용

1. HTML 파일을 불러오거나 **협죽도의 아가리 로그 열기**를 선택합니다.
2. 미리보기에서 `chatlog__message-group` 대화를 클릭합니다.
3. GM 이름과 내용을 입력하고 **선택한 대화 뒤에 추가**를 누릅니다. Ctrl/Command + Enter도 사용할 수 있습니다.
4. 추가한 GM 메시지를 선택하면 내용 불러오기, 수정 적용, 삭제가 가능합니다. **되돌리기**는 마지막 편집을 복원합니다.
5. **HTML 저장**을 눌러 `_편집본.html` 파일을 다운로드합니다. 원본 파일은 변경하지 않습니다.

동일한 이름의 기존 인물이 있으면 초상화와 메시지 색상을 재사용합니다. 내용은 일반 텍스트로 삽입하며 줄바꿈을 유지합니다. 추가한 GM 메시지는 저장 후 다시 불러와도 수정할 수 있습니다. 입력만 하고 추가하지 않은 내용은 HTML에 포함되지 않습니다.

로그는 브라우저 안에서 처리하며 서버로 업로드하지 않습니다. 외부 이미지나 글꼴을 참조하는 다른 HTML은 표시 과정에서 해당 주소에 접근할 수 있습니다. 가져온 HTML의 실행 스크립트와 이벤트 속성은 제거됩니다. 미리보기의 선택 표시와 키보드 탐색용 속성은 편집본에 포함하지 않습니다.
